# Возможности с LR

Статический сайт-визитка для презентации независимого партнёрства с LR Health & Beauty.

Опубликованная версия: https://lr-business-intro-20260911.becas-mad.chatgpt.site/

## Локальный просмотр

Из корня репозитория запустите:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:4173/. Зависимости и сборка не требуются.

## Структура

- `dist/index.html` — содержание страницы и базовые стили.
- `dist/assets/editorial.css` — актуальное оформление и адаптивная композиция.
- `dist/assets/hero.js` — воспроизведение фонового видео, обработка настроек уменьшения движения и экономии трафика.
- `dist/assets/hero-background.mp4` — полная сжатая версия фонового ролика, без звука.
- `dist/assets/hero-poster.jpg` — обложка видео.
- `.openai/hosting.json` — идентификатор сайта и каталог публикации в Sites; секретов не содержит.

Реферальная ссылка кнопки «Мой первый шаг» находится в `dist/index.html`.

## Публикация

Для обычного статического хостинга публикуйте содержимое `dist/`. Загрузка репозитория на GitHub сама по себе не включает GitHub Pages и не обновляет опубликованную версию Sites.

Фотографии, видео и обозначения брендов не получают лицензию на свободное использование вследствие размещения в этом репозитории.
